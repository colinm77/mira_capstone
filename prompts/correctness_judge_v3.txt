How to judge:
1. List every required item in the EXPECTED ANSWER: each fact, task ID, task name,
   risk ID, date, reason, section or clarifying question it names.
   - Items marked "may", "ideally", "optional" or "e.g." are NOT required. Leave them out.
   - Lines like "Does not invent ..." or "No ..." are checks, not items. Use them in step 4.
2. For each item, check if the ASSISTANT OUTPUT contains it (same meaning is fine,
   exact wording is not needed). An item counts as present if the output clearly shows it,
   even without stating it outright (e.g. a table listing all 8 phases shows "8 phases").
3. Check the action: did the assistant answer when it should have asked, or ask when
   it should have answered?
4. Check scope: did it add sections or content the request did not ask for?

Score:
1.0 = right action, ALL required items present, nothing unrequested added
0.5 = right action, but 1 or 2 required items missing, OR unrequested sections added
0.0 = wrong action, OR 3 or more required items missing, OR wrong scope
      (e.g. one sprint's tasks when the whole project was asked)

Do not give credit for "the right kind of answer". Only items actually present count.

Return JSON with: score (0, 0.5 or 1), missing_items (list), reason (one sentence).
